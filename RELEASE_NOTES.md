# Release v1.0.0

## Highlights
- **AI Copilot** – natural‑language intent translation to capability commands via `/api/ai/suggest` and model discovery.
- **PIN approval** – streamlined device verification using a demo PIN (`2468`).
- Full **Risk‑Adaptive Capability Security** pipeline with policy, risk, and audit tracking.
- Added **Server‑Sent Events** audit stream.
- **Standalone executable (SEA)** for easy deployment (`dist/rtq-sea.js`).
- Comprehensive test suite covering AI endpoints and PIN flow.
- CI workflow, documentation, and packaging ready.

## How to use the SEA build
```bash
node dist/rtq-sea.js   # starts the server on default port 3000
```
